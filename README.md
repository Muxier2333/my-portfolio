# 练品言的作品集 · Family Tree

以家族树为线索的作品集主页：把三个网页小项目挂在枝桠上，点击画框进入演示，悬停可预览封面。

## 作品列表

| 项目 | 说明 | 在线演示 |
| --- | --- | --- |
| Register Form | 表单注册与校验练习，强调输入反馈与布局节奏 | https://register-kappa-drab.vercel.app/ |
| Quiz Game | 互动问答小游戏，展示状态切换与计分逻辑 | https://quiz-game-nine-beta-55.vercel.app/ |
| Recipe Finder | 食谱检索界面，练习列表、筛选与内容呈现 | https://recipe-finder-zeta-nine.vercel.app/ |

## 文件结构

```
.
├── index.html   # 页面结构（家族树 + 项目画框 + 作品说明）
├── style.css    # 样式：Rusty Lake 风格配色、悬停放大预览
└── script.js    # 预留脚本（当前为纯静态页面，无需 JS）
```

## 技术栈

- 原生 HTML / CSS / JavaScript（纯静态，无构建依赖）
- Google Fonts（Oswald + Source Sans 3）
- SVG 手绘家族树

## 本地运行

直接用浏览器打开 `index.html` 即可，无需安装依赖。
